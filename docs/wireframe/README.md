# 운영자 대시보드 와이어프레임

소비자(공공기관·지쿠터 회사) 입장의 운영자 대시보드 저해상도 스케치입니다. 수치는 모두 자리표시자입니다.

| 화면 | 역할 |
|---|---|
| 위반 목록 | 오늘 위반 건수 요약, 기간·위반 종류·카메라별 필터, 블러된 스냅샷 표, CSV 내려받기 |
| 위반 상세 | 탐지 박스가 그려진 스냅샷, 시각·카메라·킥보드 ID·탑승자 수·신뢰도, 위반 확인 / 오탐 표시 |
| 통계 | 시간대별 위반 건수, 위반 종류 비율, 카메라·지역별 순위 |
| 설정 | 판정 구간·위반 비율·주행 이동량, 얼굴 블러(끄기 불가)·보관 기간, 알림 |

## 설계 메모
- 오탐 표시는 다음 학습용 추가 데이터로 쓰는 것을 전제로 한다.
- 얼굴 블러는 끌 수 없게 해 프라이버시 설계를 강조한다.
- 구현은 3단계에서 `feat/frontend`로 진행하며, 위반 목록과 상세 화면을 우선한다.
